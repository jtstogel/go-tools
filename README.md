# go-tools


## VSCode

When any MODULE.bazel or BUILD file changes, run:
Open command palette (`Cmd+Shift+P`) > `Tasks: Run Task` > `Generate rust project.json`.

To get intellisense with rustc output, in the command pallete, run:
Open command palette (`Cmd+Shift+P`) > `Tasks: Run Task` > `Start ibazel: (rust)`.
